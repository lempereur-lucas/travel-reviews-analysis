# TripAdvisor's Travel Reviews Analysis
Built with R(RStudio & R Markdwon).

<br>

## Where does the data come from ?
- Official source: UCI Machine Learning Repository (University of California).
- Data source: extracted (crawled) from the TripAdvisor.com website.
- Authors: Shini Renjith, A. Sreekumar, and M. Jathavedan (2018).
- Geographical context: destinations located in East Asia.

<br>

## Structure of the data
- <strong>Number of observations:</strong> 980 unique users
- <strong>Number of variables:</strong> 11 columns
  - 1 user ID
  - 10 continuous quantitative variables (activities)
- <strong>Rating rate:</strong>
  - Weighted means per user
  - Scale from 0 (Terrible) to 4 (Excellent)
- <strong>Data type:</strong>
  - Multivariable
  - Real
- <strong>Missing data:</strong> none (complete dataset)

<br>

## The Methodology
- <strong>The Exploration</strong> - Descriptive Statistics
- <strong>The Structure</strong> - Principal Composant Analysis
- <strong>The Segmentation</strong> - Hierarchical Clustering
